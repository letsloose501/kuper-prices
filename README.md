# kuper-prices

Сбор цен на продукты в [Купере](https://kuper.ru) по всем магазинам сразу — из командной строки,
без браузера и без входа в аккаунт.

Скрипт опрашивает товарный API, отсеивает мусор из выдачи, считает цену за кг/л/шт и печатает
готовую отсортированную таблицу. Задуман как «руки» для ИИ-агента: агент получает чистые данные
и занимается тем, что умеет — собирает корзину и считает, — вместо того чтобы листать карточки.

```
### творог 5
| ₽/ед | цена | объём | магазин | товар |
|---:|---:|---|---|---|
| 363 ₽/кг | 109 | 300 г | Чижик | Творог рассыпчатый Светаево 5% БЗМЖ 300 г |
| 368 ₽/кг | 140 | 380 г | Монетка | Творог рассыпчатый Першинское 5% 380 г |
| 371 ₽/кг | 130 −15% | 350 г | METRO | Творог зерненый 5% БЗМЖ 350 г |
```

## Установка

```bash
pip install curl_cffi
```

Больше ничего не нужно: ни Selenium, ни открытого браузера, ни авторизации.

Как скилл для Claude Code — скопируй папку `kuper-prices/` в `~/.claude/skills/`.
Как обычный скрипт — просто запускай `scripts/kuper.py`.

## Первый запуск: магазины под свой адрес

География Купера едет **на координатах, а не на названии города**: по соседним адресам одной сети
бывают разные `store_id`. Поэтому списка магазинов в коде нет — его нужно завести один раз:

```bash
python scripts/kuper.py --discover --lat 55.7575 --lon 37.6136 --address "Москва, Тверская 1"
```

Скрипт спросит у Купера, кто возит на эту точку, проверит каждый магазин живым запросом и запишет
подтверждённые в `scripts/kuper_stores.json` — вместе с минимальными суммами заказа. Пустой
результат существующий файл не затирает: прежний список ценнее пустого.

Координаты адреса берутся из любых карт (правый клик → «что здесь»). Файл с адресом лежит
в `.gitignore` — не публикуй его. Образец структуры — `scripts/kuper_stores.example.json`.

## Запросы

```bash
python scripts/kuper.py "творог 5:творог" "рис круглозерный:рис ! бурый"
python scripts/kuper.py --file scripts/queries.example.txt --top 2
python scripts/kuper.py "куриное филе:филе,куриное" --json
```

Формат: `запрос : якоря ! исключения`

* **якоря** — слова, которые обязаны быть в названии товара;
* **исключения** — дополнительно к встроенному чёрному списку.

**Якоря обязательны.** Поиск Купера щедро подмешивает мусор: «куриное филе» отдаёт сосиски,
«сердечки» — воздушные шары, «черника» — маску для лица, «шоколад» — молочный коктейль.

Первый якорь считается главным и должен стоять **в первых трёх словах названия**. У Купера
название начинается с самого продукта («Творог рассыпчатый…», «Филе куриное…»), поэтому одно это
правило выбрасывает «Йогурт питьевой с ЧЕРНИКОЙ» из выдачи по запросу «черника».

### Полезные флаги

| Флаг | Что делает |
|---|---|
| `--top N` | сколько дешёвых показать на запрос (по умолчанию 3) |
| `--stores METRO,Лента` | опросить только эти магазины |
| `--json` | выдать JSON вместо таблицы |
| `--no-bad` | отключить чёрный список — когда выдача пустая и надо понять почему |
| `--workers N` | сколько магазинов опрашивать разом (по умолчанию 4) |

## Если пришёл 403

Это временная защита от ботов, а не поломка. Скрипт скажет об этом прямо и вернёт код возврата 3 —
он **не выдаёт пустую таблицу за правду**. Либо подожди 10–15 минут, либо собери те же данные
браузером:

```bash
python scripts/kuper.py --emit-js "творог 5:творог"     # 1. напечатает снипет
                                                         # 2. выполнить его в открытом Купере
python scripts/kuper.py --from-clipboard "творог 5:творог"   # 3. обработать
```

Снипет кладёт сырьё в буфер обмена (или предлагает кнопку «скачать», если буфер недоступен),
а `--from-clipboard` / `--from-json` прогоняют его через ту же самую обработку — результат
идентичен прямому запросу.

## Как снимается 403

Нужны три вещи одновременно, поодиночке ни одна не работает:

1. **TLS-отпечаток Chrome** — `curl_cffi` с `impersonate="chrome"`; без него 403 всегда;
2. **заголовки** `referer`, `origin`, `x-requested-with` — без них 403 даже с верным отпечатком;
3. **прогрев** — `GET` на главную ради куки `spid`/`spsc`.

Магазины по координатам отдаёт `GET /api/v3/mweb/shelves?lat=&lon=` — полка `ui_type == "shop"`,
там же `minimum_order_amount`. Цены — `POST /api/web/v1/products` с телом `{"q", "store_id"}`.

Поле `price_per_base_human_volume` в ответе приходит пустым, поэтому цена за единицу считается
из `human_volume` (а если не разобрали — из `grams_per_unit`).

## Границы

Инструмент для личного сравнения цен: не гоняй его в цикле, не выкачивай каталог целиком,
не собирай чужие данные. Купер — независимый сервис, его API не документирован публично
и может измениться в любой момент; при странных результатах сперва прогони `--discover` заново.
