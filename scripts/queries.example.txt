# Пример списка запросов: python scripts/kuper.py --file scripts/queries.example.txt
# Формат строки:  запрос : слова-якоря (обязаны быть в названии) ! исключения
#
# Якоря не для красоты. Без них поиск подмешивает мусор: «куриное филе» отдаёт
# сосиски, «черника» — маску для лица, «шоколад» — молочный коктейль.
# Первый якорь — главный: он обязан стоять в первых трёх словах названия.
# У Купера название начинается с самого продукта («Творог рассыпчатый…»),
# поэтому это правило разом отсекает «Йогурт питьевой с ЧЕРНИКОЙ» на запрос «черника».

куриное филе : филе, куриное ! копчен, колбас
творог 5% : творог ! творожок, десерт
яйцо с1 : яйцо ! перепелин, шоколад
рис круглозерный : рис ! бурый, воздушн
овсянка геркулес : овсян ! печенье, батончик
масло оливковое : оливков, масло ! спрей
помидор : помидор ! консерв, вялен, паста
яблоки : яблок ! сок, пюре, сушен, чипс
черника замороженная : черник ! маска, крем, йогурт, варень
шоколад горький : шоколад ! молочн, глазур, халва, конфет
