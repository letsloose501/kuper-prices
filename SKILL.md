# Цены Купера

Инструмент — `scripts/kuper.py`. Зависимость одна: `pip install curl_cffi`.

## Порядок работы

**1. Завести магазины под адрес (один раз на адрес).** У Купера география едет на координатах, а не
на названии города: по соседним адресам одной сети бывают разные `store_id`. Поэтому в коде их нет.

Достаточно назвать адрес словами — координаты скрипт посчитает сам:

```
python scripts/kuper.py --discover --address "Город, улица, дом"
```

Если координаты уже известны точно, их можно передать напрямую (тогда геокодер не вызывается):

```
python scripts/kuper.py --discover --lat <широта> --lon <долгота> --address "как подписать"
```

Скрипт спросит у Купера, кто возит на эту точку, проверит каждый id живым запросом и запишет
подтверждённые в `kuper_stores.json` рядом со скриптом (он в `.gitignore` — это личные данные;
образец структуры — `scripts/kuper_stores.example.json`).

**Как ищется точка доставки** — по порядку, до первого успеха:

1. `--lat/--lon`, если переданы;
2. сохранённые координаты из `kuper_stores.json`;
3. `--address` строкой → геокодер OpenStreetMap (Nominatim): бесплатно, без ключа;
4. адрес доставки из аккаунта Купера (`/api/v2/cart-api/carts/user-context`) — сработает,
   только если сессия узнаёт пользователя; анонимной неоткуда.

⚠️ **Геокодер не выбирает за пользователя.** Нашлась одна точка — берём её и печатаем, что
именно распозналось. Нашлось несколько («Ленина 1» есть в сотне городов) — скрипт показывает
кандидатов с готовыми `--lat/--lon` и останавливается. Не нашлось — просит уточнить.
Это не перестраховка: набор магазинов и их `store_id` привязаны к точке, и промах по городу
даёт правдоподобную, но чужую выдачу.

⚠️ **«Не ответил» ≠ «не найдено», код возврата 3.** У Nominatim лимит — запрос в секунду, и
частые попытки он придерживает. Скрипт эти случаи различает: молчание геокодера не выдаётся за
плохой адрес. Увидел такое сообщение — подожди несколько секунд и повтори, адрес тут ни при чём.

Адрес нигде не сохраняется как личные данные: в конфиг идёт только подпись, которую задал
пользователь, и координаты.

Полка Купера отдаёт первую десятку магазинов, поэтому какой-то сети может не хватить: известные
`store_id` при повторном `--discover` не выбрасываются, а проверяются наравне с найденными.

**2. Спросить цены.**

```
python scripts/kuper.py "творог 5:творог" "рис круглозерный:рис ! бурый"
python scripts/kuper.py --file queries.txt --top 2 --json
```

Синтаксис: `запрос : якоря ! исключения`.

⚠️ **Якоря обязательны.** Без них поиск Купера подмешивает мусор: «куриное филе» → сосиски,
«черника» → маска для лица, «шоколад» → молочный коктейль. Первый якорь — главный: он обязан
стоять в первых трёх словах названия (у Купера название начинается с самого продукта).
Пример готового списка — `scripts/queries.example.txt`.

**3. Собрать результат.** Таблица уже отсортирована по цене за базовую единицу — первая строка
самая выгодная. Название каждого товара — ссылка на карточку, её можно открыть и посмотреть
состав, фото и отзывы. Дальше твоя работа: собрать корзину, посчитать сумму, свести к одной-двум
доставкам. Минимальные суммы заказа по магазинам лежат в `kuper_stores.json` (`min_order`).

## БЖУ и калорийность

```
python scripts/kuper.py --file queries.txt --top 2 --nutrition
```

Добавляет колонки `ккал · Б · Ж · У` — **всегда на 100 г продукта**, как и подписано на самой
карточке. Оттуда же берётся состав (виден в `--json`, в таблицу не выводится — длинный).

⚠️ **Это стоит по запросу на каждый показанный товар.** Цены собираются одним запросом на
магазин, а карточка — отдельным на товар, поэтому `--nutrition` заметно медленнее и куда
быстрее упирается в 403. Правила:

- держи `--top` маленьким (1–2): добор идёт только для тех товаров, что попали в таблицу;
- не включай флаг, когда нужны только цены;
- 403 на карточках **не роняет прогон** — цены уже собраны и останутся в таблице, у части
  товаров просто будет прочерк вместо БЖУ, а в конце появится предупреждение. Повтори через
  10–15 минут или уменьши `--top`.

Прочерк бывает и законно: у бытовой химии, посуды и прочего непищевого нутриентов нет вовсе.

Пересчёт на порцию — обычная арифметика: `grams_per_unit` из той же строки даёт вес упаковки,
значит на всю пачку это `значение × грамм / 100`.

## Что делать, если пришёл 403

Это временная защита от ботов, а не поломка. Скрипт скажет об этом прямо и вернёт код 3 —
он **не** выдаёт пустую таблицу за правду. Варианты:

- подождать 10–15 минут;
- собрать те же данные браузером: `--emit-js` печатает снипет, который выполняется на открытой
  странице Купера и кладёт сырьё в буфер обмена (или предлагает кнопку «скачать»), дальше
  `--from-clipboard` или `--from-json <файл>` — обработка та же самая, результат идентичный.

Не поднимай `--workers`: чем больше одновременных запросов, тем скорее словишь блокировку.

## Границы

Инструмент для личного сравнения цен. Не гоняй его в цикле, не выкачивай каталог целиком,
не собирай через него чужие данные.
