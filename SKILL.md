# Цены Купера

Инструмент — `scripts/kuper.py`. Зависимость одна: `pip install curl_cffi`.

## Порядок работы

**1. Завести магазины под адрес (один раз на адрес).** У Купера география едет на координатах, а не
на названии города: по соседним адресам одной сети бывают разные `store_id`. Поэтому в коде их нет.

```
python scripts/kuper.py --discover --lat <широта> --lon <долгота> --address "как подписать"
```

Скрипт спросит у Купера, кто возит на эту точку, проверит каждый id живым запросом и запишет
подтверждённые в `kuper_stores.json` рядом со скриптом (он в `.gitignore` — это личные данные).
Координаты бери из любых карт. Если у пользователя есть только адрес строкой — попроси координаты
или найди их геокодером, не угадывай.

Полка Купера отдаёт первую десятку магазинов, поэтому какой-то сети может не хватить: известные
`store_id` при повторном `--discover` не выбрасываются, а проверяются наравне с найденными.

**2. Спросить цены.**

```
python scripts/kuper.py "творог 5:творог" "рис круглозерный:рис ! бурый"
python scripts/kuper.py --file queries.txt --top 2 --json
```

Синтаксис: `запрос : якоря ! исключения`.

⚠️ **Якоря обязательны.** Без них поиск Купера подмешивает мусор: «куриное филе» → сосиски,
«черника» → маска для лица, «шоколад» → молочный коктейль. Первый якорь — главный: он обязан
стоять в первых трёх словах названия (у Купера название начинается с самого продукта).
Пример готового списка — `scripts/queries.example.txt`.

**3. Собрать результат.** Таблица уже отсортирована по цене за базовую единицу — первая строка
самая выгодная. Дальше твоя работа: собрать корзину, посчитать сумму, свести к одной-двум
доставкам. Минимальные суммы заказа по магазинам лежат в `kuper_stores.json` (`min_order`).

## Что делать, если пришёл 403

Это временная защита от ботов, а не поломка. Скрипт скажет об этом прямо и вернёт код 3 —
он **не** выдаёт пустую таблицу за правду. Варианты:

- подождать 10–15 минут;
- собрать те же данные браузером: `--emit-js` печатает снипет, который выполняется на открытой
  странице Купера и кладёт сырьё в буфер обмена (или предлагает кнопку «скачать»), дальше
  `--from-clipboard` или `--from-json <файл>` — обработка та же самая, результат идентичный.

Не поднимай `--workers`: чем больше одновременных запросов, тем скорее словишь блокировку.

## Границы

Инструмент для личного сравнения цен. Не гоняй его в цикле, не выкачивай каталог целиком,
не собирай через него чужие данные.
